# Graphic Designer Landing — Template

Responsywna strona landingowa dla grafika komputerowego. Stworzona jako prosty, statyczny szablon do szybkiego wdrożenia.

Co zawiera:
- index.html — główna strona (polski język)
- styles.css — nowoczesne style, zmienne CSS do łatwej personalizacji
- script.js — minimalne skrypty: menu i płynne przewijanie

Szybkie uruchomienie:
1. Sklonuj repo: git clone https://github.com/arturwyroslak/graphic-designer-landing-20260211.git
2. Otwórz index.html w przeglądarce.

Deployment:
- Możesz wypchnąć tę gałąź na GitHub i użyć GitHub Pages, Netlify lub Vercel do hostowania (statyczny).

Dostosowanie:
- Zmień nazwę i dane kontaktowe w index.html.
- Podmień obrazy w sekcji portfolio na własne pliki (folder /assets).
- Kolory: edytuj zmienne w styles.css (:root).
